## 3. Notes by area

### 3.1 Security

- **Secrets.** `git grep` of 12 key patterns over the tracked tree and all 103 commits found only the placeholder text `OPENAI_API_KEY=sk-...` in `tools/` and the page-settings JSON in two saved USCIS HTML files. I read the real key from the ignored file into a shell variable (without printing it) and searched every commit for that exact string: 0 commits contain it. The only `.env`-type file ever added to history is `.env.example`. `.gitignore` covers `.env`, `.env.*`, `tools/**/.env`, `.dev.vars`, `dist/`, `.wrangler/`, `node_modules/`, generated speech-test audio and local recordings. `public/audio/` is intentionally tracked. No scanner such as gitleaks was available, so this is pattern-based.
- **Network, storage, DOM.** In `src/` and `index.html` there is no `fetch`, `XMLHttpRequest`, `WebSocket`, `sendBeacon`, service worker, `localStorage`, `sessionStorage`, `indexedDB`, cookie, `innerHTML`, `dangerouslySetInnerHTML`, `eval`, `new Function` or `postMessage`. The only `window`-level navigation is the credits links (`target="_blank" rel="noopener noreferrer"`). Audio uses `new Audio()`/`speechSynthesis`; recording uses `getUserMedia` and `MediaRecorder`. Third-party origins in source: `fonts.googleapis.com`, `fonts.gstatic.com` (and `www.uscis.gov` as text). Production bundle: the same two.
- **Production run in headless Chrome** (`probe-prod-plain.json`): 6 requests, 0 console messages, no failed or blocked request, 248,096 bytes. With the SEC-01 policy (`probe-prod-with-csp.json`): same requests, the only console entry is the violation I injected on purpose.
- **Microphone and recording.** `getUserMedia` is called only after a click; tracks are stopped on stop and discard; the object URL is revoked; the recording is capped at 20 s; a microphone that arrives after a discard is released; the recorder code mentions no network or storage API and a test enforces it. Open issues: SEC-04, the missing `Permissions-Policy`, and the recognition path that sends audio to the browser maker (SEC-06). The microphone needs HTTPS (Pages provides it).
- **Worker.** 20 lines: `/api/health` and 404. No secrets, not connected to the app.
- **Hooks.** SEC-03 and SEC-05. The two save hooks run `npm test` and `npm run typecheck` through a hard-coded absolute path.
